ARCHITECTURE MEMORY
======================================================================

Project modes:
1. Batch mode:
   Runs continuously from VS Code or terminal.
   Saves source input files and OTP output rows under data/experiments/<experiment_id>/.

2. Web mode:
   Shows the process visually:
   source collection -> feature extraction -> health gate -> source hashing ->
   HG-MSEF fusion -> conditioning -> rejection sampling -> 6-digit OTP.
   Web mode must use the same pipeline and experiment storage code as batch mode.

Experiment storage contract:
data/experiments/<experiment_id>/
  manifest.json
  input/
    camera/
    microphone/
    cpu_jitter/
    scheduler_jitter/
  output/
    run_index.csv
  logs/

All files for one run share the same run_id filename stem.
Example:
  input/camera/run_000001.bin
  input/microphone/run_000001.bin
  input/cpu_jitter/run_000001.bin
  input/scheduler_jitter/run_000001.bin

output/run_index.csv columns:
  run_id
  mode
  camera_input_file
  microphone_input_file
  cpu_jitter_input_file
  scheduler_jitter_input_file
  otp
  status
  created_at
