ARCHITECTURE MEMORY
======================================================================

Project modes:
1. Batch mode:
   Runs continuously from VS Code or terminal.
   Saves source input files and OTP output rows under data/experiments/<experiment_id>/.

2. Web mode:
   Shows the process visually:
   source collection -> feature extraction -> health gate -> source hashing ->
   HG-MSEF fusion -> conditioning -> rejection sampling -> 6-digit OTP.
   Web mode must use the same pipeline and experiment storage code as batch mode.

Experiment storage contract:
data/experiments/<experiment_id>/
  manifest.json
  input/
    camera/
    microphone/
    cpu_jitter/
    scheduler_jitter/
  output/
    run_index.csv
  logs/

All files for one run share the same run_id filename stem.
Example:
  input/camera/run_000001.bin
  input/microphone/run_000001.bin
  input/cpu_jitter/run_000001.bin
  input/scheduler_jitter/run_000001.bin

output/run_index.csv columns:
  run_id
  mode
  camera_input_file
  microphone_input_file
  cpu_jitter_input_file
  scheduler_jitter_input_file
  otp
  status
  created_at

Goal:

Code files, in order:
1. src/randomiser/sources/base.py
   Define EntropySource protocol/base class:
   - name property
   - collect(run_id: str) -> SourceSample
   - is_available() -> bool

2. src/randomiser/sources/source_helpers.py
   Shared byte helpers:
   - ints_to_low_byte_stream
   - low_bits_from_ints

   - trim_or_pad only if needed for tests

3. src/randomiser/sources/cpu_jitter_source.py
   First real source.
   Use time.perf_counter_ns around repeated small CPU operations.
   Store timing deltas as raw bytes.
   Metadata: iterations, min_delta_ns, max_delta_ns, mean_delta_ns.

4. src/randomiser/sources/scheduler_jitter_source.py
   Second real source.
   Use threads and time.sleep(0) or yield loops.
   Store timing deltas as raw bytes.
   Metadata: thread_count, samples_per_thread, min_delta_ns, max_delta_ns.

5. src/randomiser/integrations/camera_backend.py
   Low-level OpenCV wrapper.
   Keep backend separate from source logic.

6. src/randomiser/sources/camera_source.py
   Capture frame, grayscale/delta if available, extract low bits.
   Gracefully fail if camera missing or permission denied.
   Metadata: frame_shape, mean_pixel, std_pixel.

7. src/randomiser/integrations/microphone_backend.py
   Low-level sounddevice wrapper.
   Keep permission/device handling here.

8. src/randomiser/sources/microphone_source.py
   Capture short PCM sample block, extract low bits or deltas.
   Gracefully fail if mic missing, muted, or permission denied.
   Metadata: sample_rate, duration_ms, channel_count, mean_amplitude.

9. src/randomiser/sources/os_random_baseline.py
   Baseline only.
   Use os.urandom for comparison, not as core project identity.

10. src/randomiser/sources/registry.py
   Map config source names to source classes.
   Used by manager, CLI, batch, and web mode.

11. src/randomiser/sources/__init__.py
   Export only stable public names.

STAGE 4 - HASHING, FUSION, CONDITIONING, AND OTP GENERATION - 55% TO 70%
======================================================================

Goal:
Turn healthy source samples into one unbiased 6-digit OTP.

Code files, in order:
1. src/randomiser/pipeline/source_hasher.py
   Hash each source independently with source name, run_id, raw bytes, and metadata digest.

2. src/randomiser/pipeline/hg_msef.py
   Implement HG-MSEF:
   - include only passed or accepted warning sources
   - sort sources by stable source name
   - combine source hashes with run context
   - use SHA-512 or BLAKE2b

3. src/randomiser/pipeline/conditioner.py
   Final cryptographic conditioning of fused bytes.
   Use hashlib only.

4. src/randomiser/pipeline/rejection_sampling.py
   Convert digest bytes to uniform int in [0, 999999].
   Use rejection sampling, not simple modulo.

5. src/randomiser/pipeline/otp_generator.py
   Format integer as exactly 6 digits with leading zeros.

Test files, in order:
1. tests/unit/test_hg_msef.py
2. tests/unit/test_conditioner.py

Done when:
OTP is always 6 digits. Leading zeros are preserved. Changing source input changes fused digest.
